# Contributor Covenant Code of Conduct

We value the participation of everyone and want contributors to have an enjoyable and fulfilling experience. Please follow this code of conduct to help ensure a welcoming environment.

1. Be respectful and considerate.
2. Be collaborative and constructive.
3. Report unacceptable behavior to the maintainers.

If you experience or witness behavior that violates this code of conduct, please open an issue and mark it for maintainers' attention.

(Adopted from the Contributor Covenant.)
