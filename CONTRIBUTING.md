# Contributing to Serenie

Thank you for considering contributing! We appreciate bug reports, feature requests, and pull requests.

## How to contribute
- Check existing issues before opening a new one.
- For bugs: open an issue with steps to reproduce and environment details.
- For features: open a feature request describing the problem and suggested approach.

## Development setup
1. Fork the repository and create a feature branch: `git checkout -b feat/my-feature`
2. Install dependencies: `python -m pip install -r requirements.txt`
3. Run tests: `pytest -q`

## Coding standards
- Follow existing code style. Use type hints where appropriate.
- Keep changes focused and well-documented.

## Commit messages and PRs
- Use clear, imperative commit messages (e.g., "Add X feature").
- Open a PR against `main` with a description of the change, context, and testing notes.
- Add tests for new behavior when possible.

## Code review
- Be responsive to review feedback and update your PR accordingly.

Thank you — contributions make Serenie better!
