# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Serenie, please report it through a GitHub private security advisory on this repository. Do not use the public issue tracker for vulnerability reports.

Please include:
- Description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact
- Suggested fix (if you have one)

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Security Updates

Security patches will be released as soon as possible after confirmation. Users are encouraged to keep their installations up to date by monitoring GitHub releases and enabling Dependabot.

## Dependencies

We maintain a secure dependency chain using:
- pip-audit for vulnerability scanning
- Dependabot for automated updates
- Pinned versions in requirements.txt

See CHANGELOG.md for dependency updates and security fixes.
