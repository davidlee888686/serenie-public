# Documentation

This folder contains user-facing documentation for Serenie.

Structure:
- docs/README.md — this file
- docs/usage.md — example usage and walkthroughs (add as needed)
- docs/architecture.md — high-level architecture notes

Contributions to docs:
- Add new pages under docs/
- Link them from docs/README.md and the top-level README
- Keep docs concise, example-driven, and versioned when necessary

To preview docs locally, use a static site generator of your choice or open the markdown files directly.
